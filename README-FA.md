# نسخه مدرن سایت کافی‌نت رضا

## فایل‌ها
- `index.html` ساختار صفحه و پنل مدیریت
- `style.css` طراحی مدرن آبی و سفید و نسخه موبایل
- `script.js` خدمات، جست‌وجو، سبد سفارش، واتساپ و پنل مدیریت
- `config.js` تنظیمات اتصال Supabase و شماره واتساپ
- `supabase-schema.sql` ساخت جداول و سطح دسترسی‌ها

## بارگذاری در GitHub
1. وارد مخزن `pcreza2021-creator/pcrezacenter` شوید.
2. شاخه `main` را باز کنید.
3. فایل‌های `index.html`، `style.css` و `script.js` را با فایل‌های جدید جایگزین کنید.
4. فایل‌های `config.js` و `supabase-schema.sql` را نیز اضافه کنید.
5. Commit changes را بزنید.
6. در GitHub Pages چند دقیقه برای انتشار صبر کنید و سپس سایت را با Ctrl+F5 تازه‌سازی کنید.

## اتصال Supabase
1. در Supabase از Project Settings > API، مقدار Project URL و anon/public key را بردارید.
2. این دو مقدار را در `config.js` جایگزین کنید.
3. فایل `supabase-schema.sql` را در SQL Editor اجرا کنید.
4. از Authentication > Users یک حساب مدیر با شماره موبایل و رمز عبور بسازید.
5. UUID همان کاربر را بردارید و دستور INSERT انتهای فایل SQL را با UUID واقعی اجرا کنید تا نقش او `admin` شود.
6. در Authentication تنظیمات ورود با Phone را فعال کنید. اگر تأیید شماره پیامکی روشن است، باید SMS Provider معتبر تنظیم شود؛ برای ورود با شماره و رمز، ساخت حساب و سیاست تأیید شماره باید با تنظیمات پروژه هماهنگ باشد.

## نکات امنیتی مهم
- فقط کلید `anon/public` را در `config.js` قرار دهید.
- هرگز کلید `service_role` را در فایل‌های سایت یا GitHub قرار ندهید.
- پنل مدیریت فقط برای حسابی باز می‌شود که در جدول `profiles` نقش `admin` داشته باشد.
- سفارش‌ها در جدول `orders` ذخیره می‌شوند و پیام واتساپ نیز برای مشتری باز می‌شود.
- این نسخه پرداخت آنلاین ندارد؛ پرداخت درگاه باید بعداً از طریق بک‌اند امن پیاده‌سازی شود.

## رفتار در صورت عدم اتصال Supabase
صفحه عمومی با فهرست خدمات داخلی و سفارش واتساپی کار می‌کند. پنل مدیریت و ذخیره سفارش در پایگاه داده تا زمان وارد کردن تنظیمات Supabase فعال نمی‌شود.
